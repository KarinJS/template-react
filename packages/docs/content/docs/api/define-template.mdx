写模板时直接 import 的 API，全部来自 `@karinjs/template-react` 主入口。

## defineTemplate

```ts twoslash
import type { TemplateDef } from '@karinjs/template-react'
// @errors: 1155
// ---cut---
const defineTemplate: <D>(def: Omit<TemplateDef<D>, '__data'>) => TemplateDef<D>
```

把「一个 React 组件 + 展示元信息」登记成模板。运行时不做加工、原样返回——价值在类型：数据类型 `D` 留在返回值里供一路推导。组件 props 已标注 `TemplateProps<D>` 时泛型自动推断；内联匿名组件再显式写 `defineTemplate<D>({...})`。

| 字段          | 类型                                    | 必填 | 说明                                           |
| ------------- | --------------------------------------- | ---- | ---------------------------------------------- |
| `name`        | `string`                                | 否   | 面板侧边栏展示名称。                           |
| `description` | `string`                                | 否   | 面板展示的模板描述。                           |
| `component`   | `React.ComponentType<TemplateProps<D>>` | 是   | 实际渲染截图的组件，异步组件也可以。           |
| `validate`    | `(data: unknown) => data is D`          | 否   | 运行时数据校验，返回 `false` 时 SSR 直接报错。 |

```tsx title="ktr/template/hello/list/index.tsx" twoslash
import { defineTemplate, type TemplateProps } from '@karinjs/template-react'

/** Hello 列表模板的数据结构。 */
export interface HelloListData {
  title: string
  users: Array<{ name: string; role: string; score: number }>
}

const HelloList = ({ data }: TemplateProps<HelloListData>) => (
  <div className="w-[640px] bg-background p-7 text-foreground">
    <h1 className="mb-5 text-2xl font-bold">{data.title}</h1>
    {/* 遍历 data.users 渲染列表行…… */}
  </div>
)

export default defineTemplate({
  name: '成员榜单',
  description: '多行重复的列表截图示例',
  component: HelloList
})
```

只有 `index.tsx` 里**默认导出** `defineTemplate(...)` 这一种写法会注册为 `<板块>/<模板>` 路由。

`validate` 示例（动态路由场景的兜底，不通过时报 `Template data validation failed`）：

```tsx twoslash
import { defineTemplate, type TemplateProps } from '@karinjs/template-react'

/** 长条小票模板的数据结构。 */
interface ReceiptTallData {
  shop: string
  rows: Array<{ name: string; price: number }>
}
declare const ReceiptTall: React.FC<TemplateProps<ReceiptTallData>>
// ---cut---
export default defineTemplate({
  component: ReceiptTall,
  validate: (data): data is ReceiptTallData =>
    typeof data === 'object' &&
    data !== null &&
    typeof (data as ReceiptTallData).shop === 'string' &&
    Array.isArray((data as ReceiptTallData).rows)
})
```

## defineMock

```ts twoslash
// @errors: 1155
// ---cut---
const defineMock: <D>(data: D) => D
```

定义一份类型安全的 TS mock，原样返回。写在模板的 `mock.ts`（固定文件名）里具名导出，面板中只读。与 `satisfies` 写法效果相同：

```ts title="ktr/template/hello/list/mock.ts" twoslash
interface HelloListData {
  title: string
  users: Array<{ name: string; role: string; score: number }>
}
// ---cut---
import { defineMock } from '@karinjs/template-react'

export const team = defineMock<HelloListData>({
  title: '模板贡献榜',
  users: [{ name: '林小满', role: '模板作者', score: 98 }]
})
```

## TemplateProps

```ts twoslash
import type { RenderContext } from '@karinjs/template-react'
// ---cut---
interface TemplateProps<D> {
  /** 当前模板使用的数据，类型由 defineTemplate 的泛型决定。 */
  data: D
  /** ktr 注入的运行时上下文。 */
  ctx: RenderContext
}
```

每个模板组件都会收到的 props。`ctx.scale` 通常为 `1`；`ctx.theme` 是调用方显式提供的主题变量，没传就是 `undefined`（框架不发明默认主题色），深色模式读 `ctx.theme?.mode`。

## TemplateDef

`defineTemplate` 参数和返回值的结构，字段同上表。隐藏字段 `__data?: D` 仅作类型占位（运行时从不读取），作用是把 `D` 保留在定义上供 `DataOf` 提取，日常不用手写。

## DataOf

```ts twoslash
import type { TemplateDef } from '@karinjs/template-react'
// ---cut---
type DataOf<T> = T extends TemplateDef<infer D> ? D : never
```

从模板定义类型里取出数据类型 `D`，典型用法是渲染封装：

```ts twoslash
import type { DataOf, LoadedRegistry } from '@karinjs/template-react'

/** 注册表类型：.ktr/registry-types.d.ts 模块增强生效后为逐路由精确类型。 */
type Registry = LoadedRegistry
// ---cut---
const renderImage = async <K extends keyof Registry & string>(templatePath: K, data: DataOf<Registry[K]>) => {
  /* ... */
}
```

`K` 是路由字面量，`DataOf<Registry[K]>` 是该模板的数据类型——写 `renderImage('hello/card', {...})` 时 data 写错编译期报红。

<Callout>
  逐路由精确类型来自 `.ktr/registry-types.d.ts` 的**模块增强**（`ktr sync` 生成），插件源码不需要 import `.ktr`
  里的任何文件；类型突然「不灵了」时先跑一次 `pnpm ktr sync`。
</Callout>
