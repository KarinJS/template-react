# 快速开始

本页把 Karin 插件项目接入 `@karinjs/template-react`，用 React 组件写一个截图模板并在群里发出第一张图片。每步结尾说清成功标志，没看到就停下来检查。

前置条件：Node.js 22+、pnpm、一个基于 Karin 官方 TypeScript 插件模板的项目。

<Steps>
<Step>
### 第 1 步：初始化

在插件项目根目录执行：

```bash
npx @karinjs/template-react init
```

交互问答四项：

- **样式方案**：选默认即继承 HeroUI 主题，`bg-surface`、`text-accent` 这类语义类开箱可用。
- **是否生成示例模板**：把官方 7 个示例（问候卡片、成员榜单、宽屏仪表盘等）复制到 `ktr/template/`，照着改即可。
- **是否生成 `src/utils/render.ts`**：模板渲染接 Karin 截图的胶水层（第 4 步要用）。
- **开发面板端口**。

按提示装依赖：

```bash
pnpm install
```

**成功标志**：项目多出 `karin.template.ts`、`ktr/template/`（含示例模板）、`src/utils/render.ts`；`tsconfig.json` 补上 `jsx: "react-jsx"`；`package.json` 补上依赖和 `template` 脚本。

<Callout type="info">从零新建项目用 `npx @karinjs/template-react create <项目名>`，之后走同一套问答。</Callout>

<Callout type="warn">
  依赖全部放 `devDependencies`，构建时整体打进 `lib/`（含 react 和本包运行时），生产环境零安装；只有 `node-karin`
  保持外部。不要只打包一半——组件和渲染器必须用同一份 React，否则 hooks 直接崩。
</Callout>

</Step>
<Step>
### 第 2 步：模板长什么样

以示例 `ktr/template/hello/card/index.tsx` 的最小形态为例：

```tsx title="ktr/template/hello/card/index.tsx"
import { defineTemplate, type TemplateProps } from '@karinjs/template-react'

interface CardData {
  title: string
  items: Array<{ label: string; value: string }>
}

const Card = ({ data }: TemplateProps<CardData>) => (
  <div className="w-155 rounded-3xl border border-border bg-background p-8 text-foreground">
    <h1 className="mb-4 text-3xl font-bold">{data.title}</h1>
    {data.items.map((item) => (
      <div key={item.label} className="flex justify-between py-2">
        <span className="text-muted">{item.label}</span>
        <strong>{item.value}</strong>
      </div>
    ))}
  </div>
)

export default defineTemplate({ name: '问候卡片', component: Card })
```

- **路径即路由**：`ktr/template/<板块>/<模板>/index.tsx` → 路由 `hello/card`；裸写 `.tsx` 不注册。
- **颜色用语义类**（`bg-background`、`text-muted`），换肤和明暗切换自动跟随，别写 `bg-white` 这类固定色。
- **JSON 示例数据放 `data/` 子目录**（如 `data/default.json`），放模板根目录不识别。

完整目录结构见 [目录约定](/docs/guide/conventions)。

</Step>
<Step>
### 第 3 步：启动开发面板

```bash
pnpm template
```

等价于 `ktr sync && ktr dev`：`sync` 扫描模板目录生成 `.ktr/` 注册表，`dev` 启动面板。

**成功标志**：浏览器自动打开面板，左侧选中"问候卡片"即见实时预览；改组件或 `data/*.json` 保存后秒级更新。端口被占用时自动换端口，并在启动详情里提示占用进程。

</Step>
<Step>
### 第 4 步：接上 Karin，发出第一张图

`src/utils/render.ts`（第 1 步选择生成后已存在）：

```ts title="src/utils/render.ts" twoslash
// @filename: ./src/dir.ts
/** 插件目录常量，见 src/dir.ts。 */
export const dir = { pluginName: 'karin-plugin-example' }
// @filename: ./src/utils/render.ts
// ---cut---
import path from 'node:path'

import { karinPathHtml, render, segment, type ImageElement } from 'node-karin'
import { createTemplateRenderer, type DataOf, type LoadedRegistry } from '@karinjs/template-react'

import { dir } from '../dir'

// ktr 侧按约定装配（包根定位、配置解析、注册表加载、CSS 定位、捕获目录）；
// outputDir 是 karin 领域的位置，由插件显式指定。
const renderTemplate = createTemplateRenderer(import.meta.url, {
  renderer: { outputDir: path.join(karinPathHtml, dir.pluginName) }
})

/** 注册表类型：.ktr/registry-types.d.ts 模块增强生效后为逐路由精确类型。 */
type Registry = LoadedRegistry

/**
 * 渲染模板并交给 Karin Puppeteer 截图，返回可直接 reply 的图片消息元素。
 */
export const renderImage = async <K extends keyof Registry & string>(
  templatePath: K,
  data: DataOf<Registry[K]>,
  options?: Record<string, unknown>
): Promise<ImageElement[]> => {
  const { success, htmlPath, error } = await renderTemplate(templatePath, data)
  if (!success) {
    throw new Error(`模板渲染失败 ${templatePath}：${error}`)
  }

  const result = await render.render({
    name: `${dir.pluginName}/${templatePath}`,
    file: htmlPath,
    selector: '#container',
    type: 'png',
    omitBackground: true,
    ...options
  })

  const list = Array.isArray(result) ? result : [result]
  return list.map((img) => segment.image(`base64://${img}`))
}
```

再加一条机器人指令 `src/apps/template.ts`：

```ts title="src/apps/template.ts" twoslash
// @filename: ./src/utils/render.ts
import type { ImageElement } from 'node-karin'

/** renderImage 桩：与 src/utils/render.ts 的真实签名一致（hello/card 的数据结构）。 */
export declare const renderImage: (
  templatePath: 'hello/card',
  data: {
    /** 主标题。 */
    title: string
    /** 副标题。 */
    subtitle?: string
    /** 键值对列表。 */
    items: Array<{ label: string; value: string }>
  },
  options?: Record<string, unknown>
) => Promise<ImageElement[]>
// @filename: ./src/apps/template.ts
// ---cut---
import { karin } from 'node-karin'

import { renderImage } from '../utils/render'

/** 触发指令：#测试模板 */
export const templateTest = karin.command('^(#)?测试模板$', async (event) => {
  const images = await renderImage('hello/card', {
    title: '来自机器人的卡片',
    items: [{ label: '状态', value: '渲染成功' }]
  })
  await event.reply(images)
  return true
})
```

`renderImage('hello/card', ...)` 的 data 有严格类型——删掉 `title` 或写成数字，`tsc` 立刻报错。

**成功标志**：`pnpm dev` 后在群里发 `#测试模板`，机器人回复卡片图片；面板数据列表自动出现并选中 `captured.json`（本次真实渲染捕获的数据）。

</Step>
<Step>
### 第 5 步：生产构建

```bash
vite build
```

前提是 `vite.config.ts` 挂了 `ktrBuildPlugin()`（来自 `@karinjs/template-react/plugin`）：打包前自动刷新 `.ktr` 注册表，打包后把 CSS 编译到 `lib/style.css`。完整配置见 [构建发布](/docs/guide/building)。

**成功标志**：`lib/` 里有 `apps/*.js`、`template-registry.js`、`mock-registry.js`、`style.css`，发布后不再需要 `ktr/template/` 源码目录。

</Step>
