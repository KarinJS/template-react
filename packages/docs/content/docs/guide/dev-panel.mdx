开发面板是跑在浏览器里的模板调试台：左边选模板和数据，中间实时预览，还能试截图、调主题。

## 启动面板

在插件项目根目录执行：

```bash
pnpm dev:panel
```

它先执行 `ktr sync` 刷新 `.ktr/` 自动注册文件，再启动开发服务器。成功后浏览器打开：

```text
http://localhost:5180/__ktr/panel/
```

想同时启动 Karin 机器人本体（测试 `#渲染模板` 的真实渲染和 captured.json 捕获闭环），改用 `pnpm dev`，面板和 Karin 开发入口同时拉起。

端口等参数在 `karin.template.ts` 配置，改完需重启生效：

```ts title="karin.template.ts"
import { defineConfig } from '@karinjs/template-react'

// 这里只保留 @karinjs/template-react 自身配置；模板、mock 和 JSON 数据全部按 template/ 约定自动发现。
export default defineConfig({
  dev: {
    port: 5180,
    host: 'localhost',
    open: false
  },
  vite: {}
})
```

- `dev.port`：开发服务器端口，面板地址的端口号跟着变。
- `dev.host`：监听地址，`localhost` 只允许本机访问。
- `dev.open`：设为 `true` 时启动后自动打开浏览器。

## 界面总览

面板是左右布局：左侧选择区，中间预览画布，预览区顶部一排工具按钮。

### 左侧：模板树

模板按**板块**分组排列（如 `hello` 板块下有 `card`、`list`），显示 `defineTemplate` 里写的 `name`。点一个模板，画布立刻渲染它。模板路由（`hello/card`）就是 `renderImage('hello/card', ...)` 要传的字符串。

### 左侧：数据文件卡片

选中模板后，下方列出它的全部数据源：TS mock（卡片带**只读**标记）和 `data/` 下的 JSON 文件。支持的操作：

- **切换**：点卡片即用这份数据重新渲染。
- **新建 / 编辑 / 删除**：管理 JSON 文件；编辑弹出 JSON 编辑器（TS mock 只读，无编辑入口）。编辑器顶部有工具条：**格式化 / 复制 / 导入 .json / 导出**（导出文件名形如 `default_20260806103000.json`），保存支持 `Ctrl/Cmd+S` 快捷键，且保存时会**容错解析**——直接粘贴 JS 对象（单引号、无引号 key、尾逗号）也能识别，解析失败会在弹窗顶部给出错误提示而不关闭弹窗。
- **刷新**：重新扫描数据文件列表——在文件系统里手动增删了 JSON 时点它。

机器人刚触发过真实渲染时，`captured` 卡片会自动出现并被选中，即 [mock 数据](./data) 讲的捕获闭环。

### 中间：预览画布

画布中央是模板渲染效果，跑在 iframe 沙盒里（沙盒即"隔离的小页面"，面板样式不会污染你的组件）。**滚轮缩放**（左上角短暂显示比例，1 秒自动隐藏）、**按住空白处拖拽平移**、**双击空白处适应**（居中并缩放到完整显示）、**按住 Ctrl/Alt 进入文本选择模式**（此时可以选中面板上的文字复制）。改代码或数据保存后画布热更新，不用刷新浏览器。

### 点击模板跳转 IDE 源码

模板跑在 iframe 沙盒里，检查器（[code-inspector-plugin](https://github.com/zh-lx/code-inspector)）注入在沙盒内部，因此需要一个"检查模式"桥接来放行鼠标事件。两种进入方式：

- **工具栏「定位」按钮**（常驻开关）：点一下进入检查模式，画布顶部出现提示条；移动鼠标选择元素（显示高亮描边和组件信息），**点击即打开编辑器并定位到源码行号**，点选成功后自动退出。
- **按住 Shift+Alt**（临时模式）：按住不放即是检查模式，松开任意键退出。

随时可按 **Esc** 退出。只在你本地开发时生效，生产构建不包含检查器。

### 顶部：工具栏

左侧显示当前模板的路由、描述和状态（数据名、面板明暗、模板明暗、模板主题），右侧按钮：

- **重载**：用当前数据重新渲染一次。
- **适应**：等同双击画布。
- **截图**：截取模板并弹出**截图预览弹窗**——网格画布与主画布同一套交互（滚轮锚点缩放、拖拽平移、双击适应），右下角还有浮动缩放控件（放大 / 缩小 / 适应画布）；底部提供：**水印开关**（默认关，开启后预览、复制、下载即时生效）、**明暗重截开关 + 重新截图**（临时换主题重新截一张，不改变模板当前主题）、**复制**到剪贴板、**下载** PNG。操作结果（复制成功/失败、下载成功等）会从顶部弹出 toast 轻提示。截图只取模板内容（框架提供的 `#container` 边界），不带画布网格背景。

### 顶部：主题设置

"面板主题"和"模板主题"是两个**互相独立**的弹窗：

- **面板主题**：只影响开发面板外壳——明暗模式（浅色 / 深色）+ 主色（预设色板或取色器自定义，可一键恢复黑白）。怎么调都不会改变画布里的模板。
- **模板主题**：只影响传给模板的 `ctx.theme`——明暗模式（`ctx.theme.mode`）+ 主色（accent 系列变量），可一键恢复"组件库默认"。

<Callout type="info">
  模板主题色**只有显式选择后才下发**给模板（通过 `ctx.theme` 和 CSS
  变量）。没选过时状态栏显示"模板主题：组件库默认"，框架不注入任何颜色变量，组件库（如
  HeroUI）按自身默认主题渲染——框架不发明默认主题色，不劫持你的设计。详见 [样式与主题](./styling)。
</Callout>

## 常用调试流程

<Steps>
<Step>

`pnpm dev:panel` 启动面板，浏览器打开 `http://localhost:5180/__ktr/panel/`，左侧选中要调的模板。

</Step>
<Step>

在数据卡片间切换，确认不同数据下渲染正常；需要新数据就点"新建"或编辑现有 JSON。

</Step>
<Step>

滚轮放大检查细节，双击恢复整体视图，点"截图"下载一张确认最终效果。

</Step>
<Step>

（可选）`pnpm dev` 同时起机器人，群里发 `#渲染模板 <路由>`，回面板看自动选中的 captured 数据是否符合预期。

</Step>
</Steps>
