本页详细讲解 ktr 框架中数据的完整流转路径，覆盖开发态和生产态两种场景。

## 完整数据链路概览

```
模板定义（defineTemplate）
       ↓
注册表生成（.ktr/）
       ↓
  ┌─────────┴─────────┐
  ↓                   ↓
开发态               生产态
面板→沙盒→渲染       SSR→HTML→截图
```

## 开发态数据流

开发态的数据流经过**面板 → 沙盒 → 渲染**三个环节。

### 1. 用户操作触发

```
用户点击模板 'hello/card'
       ↓
用户选择数据源 'basic'
       ↓
面板发起 API 请求
```

### 2. Mock API 响应

面板通过 RESTful API 获取数据：

```typescript twoslash
// 面板前端代码（React）
async function loadTemplateData(path: string, dataName: string) {
  // GET /__ktr/api/data?path=hello/card&name=basic
  const response = await fetch(`/__ktr/api/data?path=${path}&name=${dataName}`)

  return await response.json()
}
```

服务端 Mock API 处理逻辑：

```typescript twoslash
// dev/mock-api.ts（简化示意）
import * as fs from 'node:fs'
import * as path from 'node:path'

declare const config: { mockDataDir: string }
declare const loadTsMocks: (templatePath: string) => Promise<Array<{ name: string; data: unknown }>>
declare const json: (res: any, status: number, body: unknown) => void
// ---cut---
export async function handleDataRequest(req: any, res: any) {
  // GET /__ktr/api/data?path=hello/card&name=default
  const url = new URL(req.url, 'http://localhost')
  const templatePath = url.searchParams.get('path')!
  const name = url.searchParams.get('name')!

  // 优先级 1：JSON mock（面板可编辑）
  const jsonPath = path.join(config.mockDataDir, templatePath, 'data', `${name}.json`)
  if (fs.existsSync(jsonPath)) {
    const data = JSON.parse(fs.readFileSync(jsonPath, 'utf-8'))
    return json(res, 200, { name, source: 'json', readonly: false, data })
  }

  // 优先级 2：TS mock（面板只读）
  const tsMock = (await loadTsMocks(templatePath)).find((mock) => mock.name === name)
  if (tsMock) {
    return json(res, 200, { name, source: 'ts', readonly: true, data: tsMock.data })
  }

  // 未找到
  json(res, 404, { error: 'Data entry not found' })
}
```

数据源优先级：**JSON mock > TS mock**（同名时 JSON 优先，TS mock 在面板中只读）

### 3. 面板下发数据

消息协议：


### 4. 沙盒渲染组件

沙盒 iframe 加载虚拟模块 `virtual:ktr-sandbox`，监听面板消息并渲染：

```tsx twoslash
// dev/sandbox.ts 生成的虚拟模块（简化示意）
import { createRoot } from 'react-dom/client'
import type { Root } from 'react-dom/client'

declare function loadTemplateModule(path: string): Promise<{ default: any }>
// ---cut---
// 1. 预加载所有模板组件
const templates: Record<string, any> = {}

// 逐个动态导入（串行，可见进度）
const templatePaths = ['hello/card', 'user/profile']

for (let i = 0; i < templatePaths.length; i++) {
  const path = templatePaths[i]
  templates[path] = (await loadTemplateModule(path)).default

  // 上报加载进度
  window.parent.postMessage(
    {
      source: 'ktr-sandbox',
      type: 'ktr:register-progress',
      payload: { loaded: i + 1, total: templatePaths.length, path }
    },
    '*'
  )
}

// 通知面板加载完成
window.parent.postMessage(
  {
    source: 'ktr-sandbox',
    type: 'ktr:ready',
    payload: { templates: templatePaths.map((path) => ({ path })) }
  },
  '*'
)

// 2. 监听面板消息
let currentRoot: Root | null = null

window.addEventListener('message', (event) => {
  if (event.data.type === 'ktr:data') {
    const { path, data, ctx } = event.data.payload
    renderTemplate(path, data, ctx)
  }
})

// 3. 渲染函数
async function renderTemplate(path: string, data: any, ctx?: any) {
  const Component = templates[path]
  if (!Component) {
    console.error(`Template not found: ${path}`)
    return
  }

  const container = document.getElementById('container')
  if (!container) return

  // 创建或复用 React root
  if (!currentRoot) {
    currentRoot = createRoot(container)
  }

  // 渲染组件
  currentRoot.render(<Component data={data} ctx={ctx} />)

  // 4. 等待渲染稳定，测量尺寸
  await waitForStableSize(container)

  const { width, height } = container.getBoundingClientRect()

  // 5. 上报渲染完成
  window.parent.postMessage(
    {
      source: 'ktr-sandbox',
      type: 'ktr:rendered',
      payload: { path, elapsed: 0, size: { width, height } }
    },
    '*'
  )
}

// 等待元素尺寸稳定（连续 3 帧无变化）
async function waitForStableSize(element: HTMLElement) {
  let stableCount = 0
  let lastSize = { width: 0, height: 0 }

  while (stableCount < 3) {
    await new Promise((resolve) => requestAnimationFrame(resolve))

    const { width, height } = element.getBoundingClientRect()

    if (width === lastSize.width && height === lastSize.height) {
      stableCount++
    } else {
      stableCount = 0
    }

    lastSize = { width, height }
  }
}
```

### 5. 面板更新画布

面板接收沙盒上报的尺寸，调整 iframe 显示：

```typescript twoslash
// 面板代码
window.addEventListener('message', (event) => {
  if (event.data.type === 'ktr:rendered') {
    const { path, size } = event.data.payload

    // 更新画布尺寸显示
    updateCanvasSize(size.width, size.height)

    // 自动适应视口
    fitToViewport()
  }
})

function updateCanvasSize(width: number, height: number) {
  const iframe = document.querySelector('#sandbox-iframe') as HTMLIFrameElement
  iframe.style.width = `${width}px`
  iframe.style.height = `${height}px`
}

function fitToViewport() {
  const canvas = document.querySelector('.canvas-container') as HTMLElement
  const iframe = canvas.querySelector('iframe') as HTMLIFrameElement

  const canvasRect = canvas.getBoundingClientRect()
  const iframeRect = iframe.getBoundingClientRect()

  // 计算缩放比例（留 20px 边距）
  const scaleX = (canvasRect.width - 40) / iframeRect.width
  const scaleY = (canvasRect.height - 40) / iframeRect.height
  const scale = Math.min(scaleX, scaleY, 1)

  iframe.style.transform = `scale(${scale})`
}
```

### 2. 渲染器初始化

`renderImage` 内部调用 `createTemplateRenderer`：

```typescript twoslash
// runtime/template-renderer.ts（简化示意）
import { createRenderer, loadTemplateRegistry, resolveConfig, resolveTemplateStyle } from '@karinjs/template-react'

declare const findPackageRoot: (callerUrl: string) => string
// ---cut---
export function createTemplateRenderer(callerUrl: string) {
  // 1. 定位包根（从 import.meta.url 向上找 package.json）
  const root = findPackageRoot(callerUrl)

  // 惰性初始化：首次渲染时才解析配置、加载注册表
  let rendererPromise: Promise<ReturnType<typeof createRenderer>> | undefined

  return async (templatePath: string, data: any, ctx?: any) => {
    rendererPromise ??= (async () => {
      // 2. 加载配置（karin.template.ts + 默认值）
      const config = await resolveConfig({ cwd: root })

      // 3. 加载注册表（优先 .ktr/ 源文件，回退到打包产物）
      const templates = await loadTemplateRegistry({ root })

      // 4. 创建渲染器（CSS 开发态用缓存、生产态用打包产物）
      return createRenderer(templates, {
        cssPath: resolveTemplateStyle(),
        outputDir: `${config.outDir}/html`,
        captureDir: config.templateDir
      })
    })()

    const render = await rendererPromise
    return render(templatePath, data, ctx)
  }
}
```

### 3. SSR 渲染生成 HTML

```typescript twoslash
// runtime/renderer.ts（简化示意）
import * as fs from 'node:fs'
import * as path from 'node:path'
import React from 'react'
import { renderToReadableStream } from 'react-dom/server'

declare const wrapHtml: (html: string, ctx: any) => string
declare const runBeforeHooks: (plugins: any[], ctx: any) => Promise<void>
declare const runAfterHooks: (plugins: any[], html: string, ctx: any) => Promise<string>
// ---cut---
export function createRenderer(templates: Record<string, any>, options: any) {
  const { outputDir, plugins = [] } = options

  return async function render(templatePath: string, data: any, ctx?: any) {
    // 1. 获取模板定义
    const template = templates[templatePath]
    if (!template) {
      return { success: false, htmlPath: '', error: `Template is not registered: ${templatePath}` }
    }

    // 2. 执行 beforeRender 钩子
    await runBeforeHooks(plugins, { path: templatePath, data, ctx })

    // 3. React 流式 SSR：等 allReady 后一次性读出完整 HTML
    const stream = await renderToReadableStream(React.createElement(template.component, { data, ctx }))
    await stream.allReady
    const bodyHtml = await new Response(stream).text()

    // 4. 执行 afterRender 钩子（可加工 HTML）
    const html = await runAfterHooks(plugins, bodyHtml, { path: templatePath, data, ctx })

    // 5. 包装 HTML 外壳（内联 CSS + 主题变量），写入文件
    const filename = templatePath.replace(/\//g, '_') + '.html'
    const htmlPath = path.join(outputDir, filename)
    fs.mkdirSync(outputDir, { recursive: true })
    fs.writeFileSync(htmlPath, wrapHtml(html, ctx), 'utf-8')

    return { success: true, htmlPath }
  }
}
```

### 4. HTML 包装器

```typescript twoslash
// runtime/html-wrapper.ts（简化示意）
import type { ThemeContext } from '@karinjs/template-react'

declare const inlineCss: string
// ---cut---
export function wrapHtml(bodyHtml: string, options: { theme?: Partial<ThemeContext> }): string {
  const { theme } = options

  // 只注入显式提供的主题字段；未提供时不输出任何变量，组件库自身主题生效
  const themeVars = theme ? generateThemeVariables(theme) : ''
  const mode = theme?.mode

  return `<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <style>${inlineCss}</style>
</head>
<body class="${mode === 'dark' ? 'dark' : ''}"${mode ? ` data-theme="${mode}"` : ''} style="${themeVars}">
  <div id="container">${bodyHtml}</div>
</body>
</html>`
}

function generateThemeVariables(theme: Partial<ThemeContext>): string {
  const vars: string[] = []

  // 变量名与 HeroUI 语义色一一对应，只输出显式提供的字段
  if (theme.accent) vars.push(`--accent: ${theme.accent}`)
  if (theme.background) vars.push(`--background: ${theme.background}`)
  if (theme.foreground) vars.push(`--foreground: ${theme.foreground}`)
  if (theme.surface) vars.push(`--surface: ${theme.surface}`)
  if (theme.border) vars.push(`--border: ${theme.border}`)
  // 其余语义色同理，theme.vars 里的任意变量追加在最后

  return vars.join('; ')
}
```

## Mock 数据的三种来源

### 1. TS mock（`mock.ts`）

```typescript twoslash

  items: Array<{ label: string; value: string }>
```

- ✅ **代码复用**：插件代码可直接 import
- ❌ **面板只读**：不可在面板编辑
- 📍 **适合场景**：固定示例数据，作为标准参考

### 2. JSON mock（`data/*.json`）

```json title="ktr/template/hello/card/data/default.json"
{
  "title": "Karin Template React",
  "items": [
    { "label": "渲染方式", "value": "SSR HTML" },
```

特点：

- ❌ **无类型校验**：运行时解析
- ✅ **面板可编辑**：新建/编辑/删除/保存
- ✅ **快速调试**：边改数据边看效果
- 📍 **适合场景**：多组对照数据，快速迭代样式

### 3. 捕获数据（`data/captured.json`）

```typescript twoslash
import * as fs from 'node:fs'

export function captureRenderData(templatePath: string, data: any, ctx: any, templateDir: string) {
  const captureDir = path.join(templateDir, templatePath, 'data')
```

特点：

- 🤖 **自动记录**：每次真实渲染自动写入
- 📡 **实时推送**：SSE 推送给面板，自动刷新
- 🐛 **问题复现**：拿线上真实数据调试
- 📍 **适合场景**：排查渲染问题，验证边缘情况

### 数据源优先级

Mock API 的加载优先级：**JSON mock > TS mock**

```typescript twoslash
// dev/mock-api.ts（简化示意）
import * as fs from 'node:fs'

declare function loadTsMocks(templatePath: string): Promise<Record<string, unknown>>
// ---cut---
async function loadData(templatePath: string, dataName: string) {
  // 1. 优先 JSON mock（面板可编辑）
  const jsonFile = `${templatePath}/data/${dataName}.json`
  if (fs.existsSync(jsonFile)) {
    return JSON.parse(fs.readFileSync(jsonFile, 'utf-8'))
  }

  // 2. 回退 TS mock（面板只读）
  const tsMocks = await loadTsMocks(templatePath)
  if (tsMocks[dataName]) {
    return tsMocks[dataName]
  }

  throw new Error('Data entry not found')
}
```

同名时 JSON mock 优先；TS mock 在面板中显示只读标记。

## 主题变量下发机制

### 开发态：面板调整主题

```

       ↓

       ↓
```

```typescript twoslash
  )

  // 同时更新面板本地状态
  setCurrentTheme(theme)
}
```

```typescript twoslash
// 沙盒代码
declare const currentPath: string
declare const currentData: unknown
declare const currentCtx: Record<string, unknown>
declare function renderTemplate(path: string, data: unknown, ctx: Record<string, unknown>): void
// ---cut---
window.addEventListener('message', (event) => {
  if (event.data.type === 'ktr:theme') {
    const { theme } = event.data.payload

    // 重新渲染当前模板，传入新主题
    renderTemplate(currentPath, currentData, { ...currentCtx, theme })
  }
})
```

### 框架不发明默认主题

<Callout type="warn">
  **重要**：框架不发明默认主题色。`ctx.theme` 只包含调用方显式提供的字段；没人显式设置时，SSR
  和面板沙盒都不注入任何颜色变量，组件库按自身默认主题渲染。
</Callout>

```typescript twoslash
// runtime/html-wrapper.ts（示意）
function generateThemeVariables(theme?: any): string {
  if (!theme) return '' // 未提供主题，不注入任何变量

  const vars: string[] = []

  // 只输出显式提供的字段
  if (theme.accent !== undefined) vars.push(`--accent: ${theme.accent}`)
  if (theme.background !== undefined) vars.push(`--background: ${theme.background}`)
  // ... 其他字段

  return vars.join('; ')
}
```
