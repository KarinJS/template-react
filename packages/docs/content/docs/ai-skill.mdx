# AI 技能包

如果你的开发主要由 AI 助手（Kimi Code、Claude Code、Cursor 等）完成，推荐先装这个技能包：AI 动手前会先拉取本站的**最新文档**，按最新约定帮你接入或排错，而不是凭记忆瞎写。

## 安装

```bash
npx skills add KarinJS/template-react@karin-template-react
```

装完后直接对 AI 说"帮我接入 @karinjs/template-react"即可，技能会被自动触发。用 `npx skills update` 获取最新版本。

## 它做了什么

技能内置于本仓库（`skills/karin-template-react/SKILL.md`），规程三步：

1. **先取文档**：拉取本站 `llms-full.txt` 或按页拉取 `content.md`，永远以最新文档为准。
2. **再动手**：按文档约定完成接入或排错，产出代码后对照约定自查。
3. **防呆清单**：内置高频错误清单——裸 `.tsx` 不注册、JSON 要放 `data/`、不要 import `.ktr`、不要写 `id="container"`。
